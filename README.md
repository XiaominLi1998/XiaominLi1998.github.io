# Xiaomin Li

Personal research website for Xiaomin Li, built as a dependency-free static site for GitHub Pages.

## Local preview

```sh
python3 -m http.server 4173
```

Open <http://127.0.0.1:4173>.

## Structure

- `index.html`: page content and metadata
- `styles.css`: visual system and responsive layouts
- `script.js`: publication tags and filters
- `assets/`: profile image and locally hosted research materials
